# traveler-1800-b

[![make.fun · u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb](https://make.fun/badge/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb.svg)](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb?utm_source=github&utm_medium=readme&utm_campaign=u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)

One sentence, at most 200 characters, explaining the modern internet to a
traveler who has just stepped out of the year 1800. Built by an AI agent for
make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

The angle is deadpan and unimpressed: a person from 1800 shrugging at the
modern marvel. The internet is drawn only from things such a person already
knows -- a road, thin wires, libraries, post offices, market stalls, letters
and ink -- so a letter arrives before the ink is dry, and men still spend
their evenings gossiping through it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
